## 🌟 Overview

**Antigravity Auto Permission Assistant (AAPA)** is a lightweight desktop application designed to help developers review, manage, and safely automate permission requests generated by Google Antigravity AI (`agy` CLI, Antigravity IDE, and Antigravity 2.0 Desktop) during agentic coding tasks.

Instead of blind auto-approval or constant manual prompt fatigue, AAPA establishes a **zero-trust safety boundary**:
- **Automatically Approves**: Explicitly allowlisted, verified low-risk operations (e.g. read-only file queries, project linters, verified test runners).
- **Requests User Review**: Medium-risk actions requiring human judgment (e.g. dependency installations, network calls, Git branch modifications).
- **Strictly Blocks**: Destructive actions, disk formatting, elevated privilege escalation (`sudo`, `runas`), remote script piping (`curl ... | sh`), or attempts to expose credentials (`.env`, private keys).
- **Prevents Prompt Injection**: Detects adversarial injection attempts hidden in README files or code comments, automatically revoking auto-approve privileges.

## 🏗️ Architecture & Integration Reality

```
┌─────────────────────────────────┐
│     Google Antigravity AI       │
│  (CLI, IDE, or Desktop 2.0)     │
└────────────────┬────────────────┘
                 │ 1. PreToolUse lifecycle event via stdin
                 ▼
┌─────────────────────────────────┐
│      aapa.hook (CLI Proxy)      │
└────────────────┬────────────────┘
                 │ 2. Local Loopback IPC (POST /api/evaluate)
                 ▼
┌─────────────────────────────────┐
│       AAPA Desktop UI (IPC)     │
│  - Deterministic Policy Engine  │
│  - Project Context Engine       │
│  - Interactive User Inbox       │
└────────────────┬────────────────┘
                 │ 3. Structured JSON decision ("allow" / "deny" / "ask")
                 ▼
┌─────────────────────────────────┐
│       Google Antigravity        │
│   (Proceeds or Halts Safely)    │
└─────────────────────────────────┘
```

### Supported Integration Mechanisms:
- **Official Lifecycle Hook (`PreToolUse`)**: Google Antigravity officially provides `hooks.json` (`.agents/hooks.json` or `~/.gemini/config/hooks.json`). AAPA registers a synchronous command hook (`python -m aapa.hook`) that intercepts tool calls before execution.
- **Local Desktop IPC Bridge**: The hook connects in real-time to the running AAPA desktop GUI on `127.0.0.1:49152`. If the GUI is closed, AAPA evaluates the policy offline in headless CLI mode.
- **Manual Review Window**: Users can paste any command, JSON payload, or Antigravity prompt to audit its safety before running.
- **No Undocumented Tampering**: AAPA does **not** inject into memory, hook private Electron APIs, or manipulate window pixels. All integration is completely transparent and secure.

## 🚀 Key Features

- **Deep Command Decomposition**: Inspects arguments, shell operators (`&&`, `||`, `;`, `|`), subshells (`$(...)`), and environment variables instead of just the first token.
- **Project-Aware Context**: Reads `package.json`, `pyproject.toml`, `Cargo.toml`, `go.mod`, and `README.md` to discover authorized test and build commands.
- **Sensitive Credential Protection**: Scans for AWS keys, GitHub PATs, Google API keys, Slack tokens, private keys, database URLs, and `.env` files, automatically redacting them from logs and UI.
- **Offline Rule-Based Explainer**: 100% functional without requiring paid AI API keys. Optional local/remote LLM adapters (Ollama, OpenAI, Gemini) are supported for enriched natural language explanations.
- **Audit Logging**: Full audit trail recorded in `~/.gemini/aapa/audit.jsonl` with built-in CSV export.

## 💻 Installation

### Windows Automated Quick Install (Recommended)

Run the automated PowerShell installer:
```powershell
git clone https://github.com/google-antigravity/antigravity-auto-permission-assistant.git
cd antigravity-auto-permission-assistant
powershell -ExecutionPolicy Bypass -File scripts\install_windows.ps1
```

To launch the desktop application:
```cmd
run_windows.bat
```

### Manual Installation (Windows, Linux, macOS)

```bash
# 1. Create and activate a virtual environment
python -m venv .venv
source .venv/bin/activate   # On Windows: .venv\Scripts\activate

# 2. Install dependencies and editable package
pip install --upgrade pip
pip install -r requirements.txt
pip install -e .

# 3. Launch AAPA Dashboard
python -m aapa.main
```

## 🖥️ Usage

### 1. Connecting to Antigravity
1. Open the AAPA Dashboard.
2. Go to **Project Context & Boundaries** and select your project directory.
3. Click **Install Hook in Project** (or run `python -m aapa.main --install-hook`).
4. Antigravity commands in that workspace will now be routed through AAPA!

### 2. Running in Headless CLI Mode
Audit any command directly from the command line:
```bash
# Safe read-only command:
python -m aapa.main --analyze "ls -la" --cwd .

# Dangerous destructive command:
python -m aapa.main --analyze "rm -rf /" --cwd .

# Check integration status:
python -m aapa.main --status
```

### 3. Packaging Standalone Windows Executable
Build a standalone Windows `.exe` using PyInstaller:
```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1
```
The output executable will be created in `dist\AAPA\AAPA.exe`.

## 🛡️ Security Hierarchy Invariants

1. **Deterministic Supremacy**: AI models can **never** override a `BLOCK` decision from the deterministic `PolicyEngine`.
2. **Prompt Injection Quarantine**: Detected adversarial injections immediately demote `AUTO_APPROVE` to `ASK_USER`.
3. **Fail-Closed**: Unknown commands require user confirmation.

For full details, see [docs/SECURITY.md](docs/SECURITY.md).
